# Geocue — Brand Guide

**Working tagline (proposed):** Arrive, and your phone adapts.

## The mark
A location pin with a lightning-bolt cutout over a dashed midnight geofence ring: arrive somewhere, trigger the change.

## Files
| File | Use |
|---|---|
| `geocue-app-icon.svg` / `.png` | App Store / home screen icon. 1024×1024, opaque, square (the system applies the rounded mask). |
| `geocue-mark-on-light.svg` / `.png` | Transparent mark for light backgrounds. |
| `geocue-mark-on-dark.svg` / `.png` | Transparent mark for dark backgrounds. |
| `geocue-wordmark-on-light.svg` / `.png` | Mark + name + tagline for light backgrounds. |
| `geocue-wordmark-on-dark.svg` / `.png` | Mark + name + tagline for dark backgrounds. |

## Type
Headings and numbers: SF Pro Rounded (bold). Body: SF Pro (system). The wordmark SVGs reference these fonts by name, so **convert the text to outlines in a vector editor before using a wordmark in print or on the web**, otherwise it will fall back to another font on machines without them.

## Voice
Quiet, confident, low-drama. Describe what the phone will do, in the present tense, without promising what iOS does not allow.

## Name check
On 2026-10-14 a search of the US App Store found no app titled exactly "Geocue". This is not a trademark search and not a guarantee the name will be accepted: check App Store Connect name availability and run a USPTO search before committing. Alternates considered: Placemode, Rovemode.

## Icon rules
- Keep the mark inside the central ~80% of the icon canvas.
- No text on the icon.
- Check the icon at 60×60 pt and in dark, tinted and clear iOS appearances before submission.
